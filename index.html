Streamingaccounts

Spotify kan via OAuth aan jouw account gekoppeld worden. Deezer is voorbereid, maar nieuwe Deezer API-appregistraties/tokens zijn momenteel door Deezer beperkt. Als je al een geldige Deezer App ID hebt, kun je die via de backend activeren.
Tokens blijven server-side. De browser krijgt geen client secrets te zien. Ontbrekende bronnen worden niet als nul meegerekend.
